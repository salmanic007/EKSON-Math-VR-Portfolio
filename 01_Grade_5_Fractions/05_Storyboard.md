
# Storyboard: Grade 5 - The Chocolate Bar Challenge

## Scene 1: Introduction
| Element | Description |
| :--- | :--- |
| **Visuals** | Cozy kitchen environment. 3D Chocolate bar (8 squares) on table. |
| **Audio** | Narrator: "Welcome! Look at this chocolate bar..." |
| **Interaction** | Free look (360 degrees). No grabbing yet. |
| **UI/Text** | None (Immersion focus). |

## Scene 2: First Interaction (You eat 2/8)
| Element | Description |
| :--- | :--- |
| **Visuals** | 2 squares of chocolate glow (Highlight effect). A virtual plate appears. |
| **Audio** | Narrator: "Imagine you are very hungry..." |
| **Interaction** | Grab & Move: Student picks up 2 glowing squares and places them on the plate. |
| **Feedback** | Snap-to-grid effect. Text floats: "You ate 2/8". |

## Scene 3: Second Interaction (Friend eats 3/8)
| Element | Description |
| :--- | :--- |
| **Visuals** | 3 different squares glow (different color). |
| **Audio** | Narrator: "Your friend joins you..." |
| **Interaction** | Grab & Move: Student picks up 3 squares and adds them to the plate. |
| **Feedback** | Snap-to-grid effect. Text updates: "Friend ate 3/8". |

## Scene 4: The Core Question (Assessment)
| Element | Description |
| :--- | :--- |
| **Visuals** | Camera zooms on plate (5 squares total). Original bar visible in background (3 missing). |
| **Audio** | Narrator: "How many pieces did you eat together?" |
| **Interaction** | Multiple Choice (VR Pointer): Student points and clicks on the correct fraction. |
| **Options** | A) 5/16, B) 5/8, C) 6/8 |

## Scene 5: Conclusion
| Element | Description |
| :--- | :--- |
| **Visuals** | Success: Green glow + Confetti particles. Failure: Gentle highlight on pieces to recount. |
| **Audio** | Narrator: "Excellent! 2/8 plus 3/8 equals 5/8." |
| **Interaction** | "Next Lesson" button appears. |
