
# Math Content: Grade 5 - Fractions

## 1. Core Mathematical Rules
- **Fraction Definition:** A fraction represents a part of a whole. It consists of a Numerator (top number, parts we have) and a Denominator (bottom number, total equal parts).
- **Adding Like Denominators:** When adding fractions with the same denominator, the denominator remains unchanged. We ONLY add the numerators.
  - Formula: `a/c + b/c = (a + b) / c`
- **Comparing Like Denominators:** When denominators are the same, the fraction with the larger numerator is the greater fraction.
  - Rule: If `c` is constant, and `a > b`, then `a/c > b/c`.

## 2. Key Vocabulary (Arabic / English)
- Numerator (البسط)
- Denominator (المقام)
- Equivalent Fractions (كسور متكافئة)
- Whole (الكل / الوحدة الكاملة)

## 3. Visual Representation Rules
- The "Whole" must always be divided into **strictly equal** parts.
- In the VR environment, 1/8 of the chocolate bar must have the exact same volume/area as any other 1/8 piece.
