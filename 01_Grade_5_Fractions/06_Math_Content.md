        <h2>1. Core Mathematical Rules</h2>
        
        <div class="rule-box">
            <h3>Fraction Definition</h3>
            <p>A fraction represents a part of a whole. It consists of:</p>
            <ul>
                <li><strong>Numerator</strong> (top number): parts we have</li>
                <li><strong>Denominator</strong> (bottom number): total equal parts</li>
            </ul>
        </div>

        <div class="rule-box">
            <h3>Adding Like Denominators</h3>
            <p>When adding fractions with the same denominator, the denominator remains unchanged. We ONLY add the numerators.</p>
            <div class="formula">a/c + b/c = (a + b) / c</div>
        </div>

        <div class="rule-box">
            <h3>Comparing Like Denominators</h3>
            <p>When denominators are the same, the fraction with the larger numerator is the greater fraction.</p>
            <div class="formula">If c is constant, and a > b, then a/c > b/c</div>
        </div>
